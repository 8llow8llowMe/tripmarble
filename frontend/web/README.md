## TripMarble Web Repository

React + Next.js 기반의 TripMarble 웹앱 레포지토리입니다.

---

### Version

- Next.js 14.2.5
- React 18.2.0
- Sass 1.77.8
- TypeScript 5.x
- react-redux 9.1.2
- redux persist 6.0.0
- npm 사용

---

### Scripts

```bash
npm run dev       # 개발 서버 실행
npm run build     # 프로덕션 빌드
npm run start     # 빌드된 앱 실행
```
